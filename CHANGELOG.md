## [Baseline 1] - 2026-08-05

### Status
Initial Architectural Baseline established.

### Frozen Documents

- FRAMEWORK_SPEC.md v1.1.0
- ARCHITECTURE.md v2.0.0
- RUNTIME_ARCHITECTURE.md v1.0.0

### Summary

This baseline establishes the authoritative architectural foundation of the EduTeX Framework.

The following aspects are considered frozen:

- Framework vision and design philosophy.
- Static architectural model.
- Runtime execution model.
- Documentation hierarchy.
- Architectural terminology.
- Runtime terminology.

Future modifications to these documents SHALL only occur when:

- an ambiguity is identified during specification generation;
- an implementation constraint requires an architectural revision;
- a new architectural capability is introduced.

Component Specifications generated after this baseline SHALL conform to these authoritative documents.
