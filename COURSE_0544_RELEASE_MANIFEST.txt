EduTeX 0.5.44 - Quality report diagnostics contract

Scope
- Add Q012, a deterministic diagnostics contract for malformed quality reports.
- Verify valid reports are silent and corrupted reports identify missing sections,
  status drift, identity drift, and summary drift.
- Preserve edutex.quality-baseline.v1 and Q001-Q011 behavior.
- Document QL-019.

Changed files
- tools/quality_check.py
- tests/test_quality_check.py
- docs/quality_process_spec.md

Compatibility
- Q012 is additive. Runtime CLI behavior is unchanged.
- Q001-Q011 identifiers and semantics remain unchanged.
- No installation, network access, or global executable lookup is used.

Validation performed in the offline agent
- Python compilation: PASS.
- Q012 valid and malformed report diagnostics: PASS.
- Twelve-check catalog and execution plan: PASS.
- Q010 schema and Q011 consistency contracts: PASS.
- Full pytest suite: to be run after applying the archive.

PowerShell commands
Run these from the repository root.

Apply the release archive:
  tar -xzf .\\edutex_0.5.44_quality_report_diagnostics_contract.tar.gz -C .

Run syntax validation:
  python -m compileall -q .\\tools .\\tests

Run focused validation:
  python -m pytest -q .\\tests\\test_quality_check.py

Run complete validation:
  python -m pytest -q

Run the quality baseline:
  python .\\tools\\quality_check.py --verbose
  python .\\tools\\quality_check.py --json
