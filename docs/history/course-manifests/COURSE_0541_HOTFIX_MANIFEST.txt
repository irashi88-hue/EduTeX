EduTeX 0.5.41 release metadata contract test hotfix

Problem fixed
The Q009 catalog extension correctly changed the expected catalog size from
eight to nine checks, but three focused test expectations were not updated:
- the all-passed status fixture omitted Q009;
- the extra-results summary fixture still contained only eight results;
- the ordered report fixture still expected eight checks and omitted Q009 from
the catalog list.

Change
- tests/test_quality_check.py
  - Added Q009 to the all-passed status fixture.
  - Added Q008 to the extra-results fixture while preserving its unknown extra
    result, so the fixture contains nine results as expected.
  - Updated the ordered report fixture to expect nine checks and the Q009 catalog
    entry.

No production code changed. Q009 release metadata validation, the
edutex.quality-baseline.v1 report schema, and Q001-Q009 implementation remain
unchanged.

Apply from the repository root in PowerShell:
  tar -xzf .\\edutex_0.5.41_release_metadata_contract_hotfix.tar.gz -C .

Run focused validation:
  python -m pytest -q .\\tests\\test_quality_check.py

Run complete validation:
  python -m pytest -q

Run the quality baseline:
  python .\\tools\\quality_check.py --verbose
  python .\\tools\\quality_check.py --json
