EduTeX 0.5.48 - Quality report serialization contract

Scope
- Add Q016, a deterministic contract check for JSON report serialization.
- Verify complete, failed, and incomplete reports serialize deterministically,
  round-trip through JSON, use sorted keys, and have newline-terminated output.
- Preserve edutex.quality-baseline.v1 and Q001-Q015 behavior.
- Document QL-023.

Changed files
- tools/quality_check.py
- tests/test_quality_check.py
- docs/quality_process_spec.md

Compatibility
- Q016 is additive. Runtime CLI behavior is unchanged.
- Q001-Q015 identifiers and semantics remain unchanged.
- No installation, network access, or global executable lookup is used.

PowerShell commands
Run these from the repository root.

  python -m compileall -q .\tools .\tests
