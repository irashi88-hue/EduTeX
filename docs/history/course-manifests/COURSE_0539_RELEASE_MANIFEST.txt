EduTeX 0.5.39 - Build JSON error contract

Scope
- Add structured JSON error output for expected build failures when the build
  command is invoked with --format json.
- Preserve the existing successful and lint-blocked JSON payload shapes.
- Keep text-mode Click diagnostics unchanged.
- Add focused tests for missing Knowledge Model and missing configuration errors.
- Document the build JSON error contract.

Changed files
- src/edutex/core/cli.py
  - Added build --format text|json.
  - Added _format_build_error_json().
  - Serialized EduTeXError and OSError build failures as JSON.
- tests/test_build_lint_json.py
  - Added structured error tests for missing Knowledge Model and configuration.

Compatibility
- Text-mode build behavior remains unchanged.
- Existing successful JSON payloads remain unchanged.
- Existing lint-blocked JSON payloads remain unchanged.
- JSON build failures use top-level keys lint and build, with build.status=failed
  and an error object containing type and message.

- Missing configuration JSON error: PASS.
- No Click Error prefix in JSON output: PASS.
- Existing successful/blocked JSON contract: PASS.

PowerShell commands
Run these from the repository root.

Apply the release archive:
  tar -xzf .\edutex_0.5.39_build_json_errors.tar.gz -C .

Run syntax validation:
  python -m compileall -q .\src .\tests

Run the focused test module:
  python -m pytest -q .\tests\test_build_lint_json.py

Run the complete test suite:
  python -m pytest -q

Build with structured output:
  edutex build --project . --format json
