## Introduction

The Italian present tense (*presente indicativo*) is used to describe current actions, habitual actions, and general truths.

::: rule
title: Present Tense — Regular -ARE verbs
Regular -ARE verbs drop the infinitive ending and add the following endings:
-o, -i, -a, -iamo, -ate, -ano.
:::

::: example.simple
title: Parlare (to speak)
Io **parlo** italiano. — I speak Italian.
Tu **parli** bene. — You speak well.
:::

::: note
title: Subject Pronouns
In Italian, subject pronouns (io, tu, lui/lei...) are often omitted because the verb ending already indicates the subject.
:::

::: vocab
word: parlare
translation: to speak
gender: —
plural: —

:::

::: conjugation
