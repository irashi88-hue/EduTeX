# あいさつと自己紹介

日本語で人に会ったときのあいさつと、簡単な自己紹介を練習します。

::: rule
title: 基本のあいさつ
朝は「おはようございます」、昼は「こんにちは」、夜は「こんばんは」と言います。
:::

::: example.simple
title: はじめまして
はじめまして。ルカです。どうぞよろしくお願いします。
(Nice to meet you. I am Luca.)
:::

::: vocab
word: こんにちは
translation: hello
gender: —
plural: —
example: こんにちは、ルカさん。
:::

::: exercise
title: 自己紹介を完成させましょう
「はじめまして。私は＿＿＿です。」の空欄に名前を書きましょう。
::: solution
ルカ
:::
:::
