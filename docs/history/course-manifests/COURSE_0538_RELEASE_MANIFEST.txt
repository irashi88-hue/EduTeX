EduTeX 0.5.38 - Quality report contract closure

Scope
- Close the quality-report work at a pragmatic 7/10 maturity level.
- Add quality_baseline_report_diagnostics(report) for observational contract checks.
- Validate report check list shape, check identity, passed/status agreement, and
