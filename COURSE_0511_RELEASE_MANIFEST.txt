EduTeX 0.5.11 — PDF runtime validation contract

Scope
- Harden Q007 with explicit compiler selection for standard and CJK courses.
- Recognize latexmk, pdflatex, and xelatex according to the language path.
- Validate compiled PDFs with qpdf when available.
- Validate extracted text with pdftotext when available.
- Validate Title, Author, and Subject with pdfinfo when available.
- Load PDFs with pypdf when available and check the document language when exposed.
- Render the first page with pdftoppm when available.
- Add focused helper tests for compiler selection, pdfinfo parsing, and metadata mismatches.
- Document the expanded runtime gates.
