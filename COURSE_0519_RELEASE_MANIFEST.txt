EduTeX 0.5.19 - Runtime summary/report alignment

Scope
- Align pdf_runtime_summary(language) with pdf_runtime_report(language).
- Derive compact compiler, language, gate, status, and missing-gate fields from
  the detailed report instead of probing independently.
- Preserve all existing summary fields and add normalized diagnostic fields.
- Add focused tests for standard and CJK compiler alignment, missing qpdf, and
  report/summary field equality.
- Include copyable PowerShell commands for applying and testing the release.

- tools/quality_check.py
- tests/test_quality_check.py
- docs/quality_process_spec.md

Apply from the repository root in PowerShell:
  tar -xzf .\edutex_0.5.19_runtime_summary_alignment.tar.gz -C .

Print the compact summary:
  python -c "from tools.quality_check import pdf_runtime_summary; import json; print(json.dumps(pdf_runtime_summary(), indent=2, sort_keys=True))"

Print the structured report:
  python -c "from tools.quality_check import pdf_runtime_report; import json; print(json.dumps(pdf_runtime_report(), indent=2, sort_keys=True))"

Run focused checks:
  python -m compileall -q .\tools .\tests
  python -m pytest -q .\tests\test_quality_check.py

Run the normal project checks:
  python -m pytest -q
  python .\tools\quality_check.py --verbose
