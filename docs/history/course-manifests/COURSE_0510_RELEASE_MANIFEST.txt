EduTeX 0.5.10 — Quality baseline PDF/LaTeX contract

Scope
- Extend the local quality baseline with Q007 PDF/LaTeX accessibility contract.
- Verify generated LaTeX markers for text mapping, Unicode, bookmarks, and PDF metadata.
- Verify compiled PDF structure with qpdf when a LaTeX compiler is available.
- Verify extracted PDF text with pdftotext when available.
- Keep the check environment-aware: missing LaTeX compilers skip only the compiled-PDF sub-check.
- Add pure-helper tests and update the quality process specification.

Apply from the repository root in PowerShell:
