EduTeX 0.5.41 - Release metadata contract

Scope
- Add Q009, a deterministic release metadata integrity check.
- Require a valid semver in pyproject.toml and CLI_VERSION.
- Require the project and CLI versions to match.
- Require the edutex console entry point to target edutex.core.cli:main.
- Add focused tests for coherent metadata, version mismatch, missing/invalid
  versions, and entry point mismatch.
- Align the repository project version with the restored CLI version 0.3.0.

  schema.

Q009 contract
- pyproject.toml exists and is valid TOML;
- [project].version is valid semver;
- src/edutex/core/cli.py contains a valid CLI_VERSION;
- project version and CLI version are identical;
- project.scripts.edutex equals edutex.core.cli:main.

Compatibility
- edutex.quality-baseline.v1 remains unchanged.
- Q001-Q008 identifiers and semantics remain unchanged.
- The check performs no installation, network access, or global CLI lookup.
- Runtime CLI behavior is unchanged.
