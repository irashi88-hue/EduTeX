# CONTRIBUTING

Grazie per l'interesse verso questo progetto.

Attualmente il progetto è sviluppato principalmente dall'autore, ma vengono seguite alcune convenzioni per mantenere uno stile uniforme.

---

# Struttura

- Un argomento = un capitolo.
- Un capitolo = un file `.tex`.

---

# Convenzioni editoriali

Ogni capitolo deve contenere:

1. Introduzione
2. Spiegazione
3. Regole
4. Esempi
5. Errori comuni
6. Curiosità
7. Lessico
8. Esercizi
9. Soluzioni

---

# Convenzioni del codice

- Utilizzare esclusivamente le macro definite nel preambolo.
- Evitare codice duplicato.
- Commentare il codice solo quando necessario.

---

# Commit

Convenzione:

```
feat:
fix:
docs:
style:
refactor:
```

Esempi:

```
feat: aggiunto capitolo sul Perfekt

fix: corretti esempi del Dativ

docs: aggiornata roadmap
```

---

# Branch

- main → stabile
- develop → sviluppo
