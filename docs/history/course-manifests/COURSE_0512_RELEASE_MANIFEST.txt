EduTeX 0.5.12 — PDF runtime diagnostics

Scope
- Add a stable PDF tool availability snapshot to the quality runner.
- Report selected compiler and optional inspection tools for the requested language.
- Make Q007 verbose skip output explain the missing compiler and available tools.
- Preserve environment-aware behavior: no tool installation and no false failure
  when LaTeX compilers are absent.
- Add tests for CJK compiler fallback and runtime summary reporting.
- Document the diagnostic contract and copyable PowerShell commands.

- docs/quality_process_spec.md

Apply from the repository root in PowerShell:
  tar -xzf .\\edutex_0.5.12_pdf_runtime_diagnostics.tar.gz -C .

Run the focused checks:
  python -m compileall -q .\\tools .\\tests
  python -c "from tools.quality_check import pdf_runtime_summary; import json; print(json.dumps(pdf_runtime_summary(), indent=2))"

Run the normal project checks:
  python -m pytest -q
  python .\\tools\\quality_check.py --verbose
