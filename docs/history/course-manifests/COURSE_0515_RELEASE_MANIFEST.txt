EduTeX 0.5.15 - Explicit compiled PDF gate statuses

Scope
- Add inspection_gates to edutex.pdf-runtime.v1 with availability, role, and
  status for qpdf, pdftotext, pdfinfo, pdftoppm, and optional pypdf.
- Make Q007 report effective compiled-PDF gate outcomes in its detail string.
- Distinguish passed, failed, and unavailable optional checks.
- Preserve the compact pdf_runtime_summary() API and existing check names.
- Add focused tests for gate status reporting and JSON serialization.
- Include copyable PowerShell commands for applying and testing the release.

Compatibility
- Existing Q001-Q007 names and behavior remain unchanged.

  additive field.

Apply from the repository root in PowerShell:
  tar -xzf .\edutex_0.5.15_pdf_gate_status.tar.gz -C .

Print the structured report:
  python -c "from tools.quality_check import pdf_runtime_report; import json; print(json.dumps(pdf_runtime_report(), indent=2, sort_keys=True))"

Run focused checks:
  python -m compileall -q .\tools .\tests
  python -m pytest -q .\tests\test_quality_check.py

Run the normal project checks:
  python -m pytest -q
  python .\tools\quality_check.py --verbose
