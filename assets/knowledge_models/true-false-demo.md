## Saluti in tedesco

Leggi le affermazioni e indica se sono vere o false.

::: exercise
title: Verifica le affermazioni
type: true_false
statement: “Hallo” può essere usato per salutare qualcuno.
answer: vero
statement: “Tschüss” significa “buongiorno”.
answer: falso
statement: “Guten Morgen” si usa al mattino.
answer: true
:::
