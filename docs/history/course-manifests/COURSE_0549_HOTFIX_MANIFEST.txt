EduTeX 0.5.49 Q017 recursion hotfix

Problem fixed
- Q017 executed the complete quality CLI in a subprocess.
- That child executed Q017 again, causing recursive subprocess creation and an
  apparent hang around the pytest progress point.

Change
- tools/quality_check.py
  - Q017 subprocess probes set the private EDUTEX_Q017_PROBE=1 flag.
  - The probe child executes Q001-Q016 only while producing the public report.
  - The normal production plan remains Q001-Q017 and is restored after probing.

Compatibility
- Production catalog, execution order, report schema, and CLI flags are unchanged.
- Q001-Q016 behavior is unchanged.
- No network access, installation, or global executable lookup is used.

PowerShell commands
Run these from the repository root.

Apply the hotfix:
  tar -xzf .\\edutex_0.5.49_quality_cli_json_output_contract_hotfix.tar.gz -C .

Run focused validation:
  python -m compileall -q .\\tools .\\tests
  python -m pytest -q .\\tests\\test_quality_check.py

Run complete validation:
  python -m pytest -q

Run the quality baseline:
  python .\\tools\\quality_check.py --verbose
  python .\\tools\\quality_check.py --json
